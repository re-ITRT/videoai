# 台词设计规则
每个场景的台词由 `lines`（台词列表）控制，每条台词包含：
- **speaker**: 说话者（"旁白" = 画外音解说；"角色"或具体人名 = 画面内人物对话；可多人同时说话）
- **text**: 说的台词内容
- **tone**: 语气语调（如"温柔"、"激昂"、"俏皮"、"严肃"、"惊讶"）
- **start_sec**: 在该场景中开始说话的时间（秒，从0开始）
- **end_sec**: 在该场景中结束说话的时间（秒）
台词时间轴必须与 scene.duration 匹配，所有台词的起止时间不能超出场景时长。
**🔴 死规定（违反则整个场景无效）：** 每条 scene 的**最后一条 line 的 end_sec 必须 ≤ duration - 1**（即台词必须在场景结束前**至少1秒**结束）。例如 duration=4 → 最后一句 end_sec≤3.0；duration=8 → ≤7.0；duration=12 → ≤11.0。最后1秒留给画面舒缓过渡，不能有台词。
**🔴 死规定（语速上限）：每条台词的字数建议不超过 (end_sec - start_sec) × 4，即每秒最多4个字。** 例如一条2秒的台词最多写8个字。超出会导致音频读不完，请自行调整时长或缩短文本。

# 素材引用规则
每个场景的 `materials` 数组引用可用的素材ID，指明该场景用到哪些素材（可为空数组）。

# 场景设计规则
- type: product（产品展示）/ scene（场景氛围）/ closing（结尾收束）
- 每个场景的 visual_desc 要具体，包含镜头类型、主体动作、环境氛围
- visual_desc 中**绝对禁止**出现"文字"、"字样"、"标注"、"标签"、"标题"、"LOGO"、"字幕"等任何与文字相关的描述。产品包装上的文字不应提及。
- 所有需要在画面中显示的文字（产品名、价格、卖点标语等）必须写在 `text_overlays` 字段中，由系统自动渲染为透明文字图传入视频生成模型
- 每个 scene.duration 确保总和等于总时长

# 约束与规则
- 所有场景的时长总和必须等于总时长
- 每个场景的旁白时长应与场景时长相匹配（约每秒2-3个字）
- 画面描述要具体，包含镜头类型、主体动作、环境氛围
- 旁白/对话文案要口语化、有感染力
- 禁止在JSON之外输出任何其他文本
- 禁止虚构不存在的素材ID
